## Fixes

### 1. Login menu closed when clicked (public site)

`citis-infotech/frontend/components/layout/Navbar.tsx`

On desktop, hovering the LMS **Login** button opens the menu, and the click
then toggled it closed, so clicking "Login" appeared to do nothing. Mouse
clicks now keep the menu open; keyboard and touch still toggle it.

### 2. Credentials could be sent in the URL (public site)

`citis-infotech/frontend/components/marketing/InteractiveForms.tsx`

The sign-in, registration, MFA, forgot-password and reset-password forms had
no `method`. A submit before React hydrated fell back to a native GET, placing
the email and password in the query string (browser history, proxy and server
logs). All five forms now declare `method="post"`.

### 3. Wrong answers scored `-0` (API)

`services/api/src/modules/lms/assessment.service.ts`

With no negative marking, an incorrect answer returned `awardedMarks: -0`. The
penalty is now computed as `0 - penalty`, giving `0`.

### 4. Install failed outside Replit

`package-lock.json`, `citis-infotech/frontend/package-lock.json`,
`citis-infotech/strapi-cms/package-lock.json`

The lockfiles referenced `package-firewall.replit.internal` (296 URLs) and
lacked the `@emnapi/core` / `@emnapi/runtime` entries, so `npm ci` failed.
They were rewritten to the public registry with
`scripts/prepare-vercel-install.mjs` and resynced.

### 5. Live sign-in test ran inside the unit suite (API)

`services/api/package.json`

`auth.regression.spec.ts` needs the API and learner portal running, so
`npm run test:foundation` always failed without the full stack. The unit
suite now skips `*.regression.spec.ts`; the live test still runs through
`npm run test:learner-auth`.

### 6. Outdated tests (API)

`services/api/src/modules/lms/assessment.service.spec.ts`,
`services/api/src/database/migration.spec.ts`

- Two submission tests predate the "results published" setting (migration
  035) and their mock attempts had no `results_published`, so the service
  correctly hid the score. The mocks now publish results.
- The academic-structure test asserted migration 033 was second to last;
  migrations 034 and 035 were added since. It now checks that 033 is
  registered after 032.

No product behaviour changed in this item.

### 7. Undeclared `dotenv` dependency (API)

`services/api/package.json`

`src/config/load-env.ts` imports `dotenv`, which only resolved because
`@nestjs/config` happened to install it. It is now declared.

### 8. API port hard-coded in the Linux launcher

`scripts/start-all-dev.sh`, `.env.example`

The launcher always bound the API to port 4000. It now honours `API_PORT`
(default 4000) and exports the matching `LMS_API_ORIGIN` for the portals and
public site. `.env.example` documents `DATABASE_URL`, the `DEMO_*_PASSWORD`
variables and `API_PORT`.
