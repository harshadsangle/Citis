---
name: LMS provider branding
description: Certification catalogue headers must use contained provider-specific marks rather than a shared generic icon.
---

Use provider-specific local artwork in the LMS certification catalogue, sized with both maximum width and height so every mark remains fully visible in its compact tile.

**Why:** Live preview review exposed that a generic award icon hid the provider distinction and that a wide wordmark was clipped in the fixed-size tile.

**How to apply:** When adding or changing certification providers, verify the rendered catalogue header in the browser at both the unfiltered catalogue and provider-filtered views.
