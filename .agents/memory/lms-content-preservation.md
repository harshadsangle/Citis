---
name: LMS content preservation
description: Preserve official LMS PDFs, learning materials, course content, and resources during branding or provider-reference cleanup.
---

Never remove or modify LMS PDFs, learning materials, course content, or learning resources when removing a provider from the website or LMS UI.

**Why:** The user explicitly requires existing LMS content and source materials to remain unchanged; only UI-facing references, links, branding, and integrations are in scope.

**How to apply:** Limit provider cleanup to application code, rendered labels, navigation, external links, metadata shown in the UI, and integrations. Do not rewrite, sanitize, replace, or delete source files or persisted course-resource content.
