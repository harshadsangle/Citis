name: Unity objective imports
description: Durable rules for Unity Certified User catalogue and objective-resource imports.
---

Unity Certified User Artist, Programmer, and VR Developer are distinct role-based certification tracks, even when they share the same product and preparation-hour guidance. Keep each official objective PDF attached once to its own course and preserve the top-level objective areas as the course structure.

**Why:** The supplied Unity documents define different competencies and exam outcomes; combining them would make the catalogue ambiguous and weaken role-specific portal filtering.

**How to apply:** Use stable role-specific course codes, keep the shared provider programme separate from course identity, attach each source PDF idempotently, and use a neutral Unity wordmark for provider branding rather than a role-specific badge.
